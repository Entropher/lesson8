# Lesson 8 - Services Section Layout

A front-end development homework project demonstrating responsive header navigation and a services card grid layout.

## Features

- **Header Navigation**: Styled header with logo, navigation links, and contact button
- **Services Section**: Grid layout displaying three service cards with descriptions
- **Hover Effects**: Interactive navigation links with animated underlines
- **Responsive Design**: Built with flexbox for flexible layouts

## Files

- `index.html` - Main HTML structure
- `style.css` - Styling and layouts
- `src/images/` - Image assets (logo)

## Technologies Used

- HTML5
- CSS3
